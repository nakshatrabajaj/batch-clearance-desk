# Batch Clearance Desk

A browser tool for Bajaj Formulations production planning. It works with three FINAMAN ERP exports:

1. **Total Pending** (order report) and **Batch Clearance** (Concise + Details): lists every pending order with no matching work order line, in the batch clearance Excel format.
2. **Graphics CSV** (BF_GRAPHICS): removes every batch clearance line whose brand is still in Graphics and gives the remaining pendency. Click any number in the RM/PM matrix to see its brands, what each is short of, the shortage per material and each brand's requirement, all downloadable as Excel.

All files are read inside your browser. Nothing is uploaded or stored.

Open it at: https://nakshatrabajaj.github.io/batch-clearance-desk/
